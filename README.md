# 🎁 The Gift Affair

### Discover Thoughtful Gifts for Every Special Moment

**The Gift Affair** is a modern, responsive wedding gift discovery website designed to help users explore creative and thoughtful gift ideas for different wedding occasions, recipients, and budgets.

The project focuses on creating an attractive and user-friendly frontend experience with colourful UI elements, smooth animations, intuitive navigation, and responsive layouts.

## ✨ Key Features

### 1. Homepage
- Modern and attractive landing page.
- Engaging hero section.
- Featured gift collections.
- Popular categories and occasions.
- Curated gift recommendations.
- Clear navigation and call-to-action buttons.

### 2. Gift Discovery
- Browse different wedding gift ideas.
- Search and explore gift collections.
- Filter gifts by category and occasion.
- Explore gifts based on recipients and budgets.
- View gift details and images.

### 3. Gift Categories and Guides
- Explore gifts for different wedding ceremonies.
- Browse gifts based on recipients.
- Discover curated gift collections.
- View personalized gift inspiration.

### 4. Admin Dashboard UI
- Admin dashboard interface.
- Gift management interface.
- Category and occasion management screens.
- Gift creation and editing forms.
- Gift guide management interface.

*Note: Admin features are frontend interfaces only and do not provide actual backend functionality.*

### 5. Responsive Design
- Desktop, tablet, and mobile-friendly layouts.
- Responsive navigation.
- Modern cards and interactive UI elements.
- Smooth animations and transitions.
- User-friendly interface.

### 6. Additional Pages
- About Us
- Contact Us
- Privacy Policy
- Terms and Conditions

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Next.js 16 | Frontend framework |

| TypeScript | Type-safe development |
| Tailwind CSS 4 | Styling and responsive design |
| Framer Motion / Motion | Animations and transitions |
| Lucide React | Icons |
| React Hook Form | Frontend form handling |
| Zod | Form validation |

## 🚀 Installation and Setup

### Prerequisites

- Node.js
- npm
- Git

### Step 1: Clone the Repository

```bash
git clone https://github.com/Rezwan-Nabi/The-Gift-Affair.git
```

### Step 2: Navigate to the Project Folder

```bash
cd "The-Gift-Affair/The Gift Affair"
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start the Development Server

```bash
npm run dev
```

### Step 5: Open in Browser

Visit:

```text
http://localhost:3000
```
